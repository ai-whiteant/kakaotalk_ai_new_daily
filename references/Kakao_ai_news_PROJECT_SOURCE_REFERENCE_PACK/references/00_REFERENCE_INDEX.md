-   공식 URL을 Source of Truth로 사용한다.
-   이 MD 파일에는 프로젝트에 필요한 핵심 사항만 기록한다.
-   API Key, Access Token, Client Secret, Refresh Token은 절대 기록하지
    않는다.

-   API 변경 확인 시 `최종 확인일`과 `변경 메모`만 갱신한다.
